# nickkalkounis.com

Personal site, served with GitHub Pages. Plain HTML and one stylesheet; no build step.

| Path | What |
|---|---|
| `/` | Home page |
| `/boomerang-tasks/` | Boomerang Tasks support (App Store support URL) |
| `/boomerang-tasks/privacy.html` | Boomerang Tasks privacy policy |
| `/copypasta/` | CopyPasta support (App Store support URL) |
| `/copypasta/privacy.html` | CopyPasta privacy policy |

App pages are reachable but not linked from the home page. When an app goes live on the
App Store, add it to the commented-out **Apps** section in `index.html`.

## Custom domain

Once DNS points at GitHub Pages, set the custom domain to `nickkalkounis.com` in
Settings → Pages (this adds a `CNAME` file) and turn on Enforce HTTPS.
